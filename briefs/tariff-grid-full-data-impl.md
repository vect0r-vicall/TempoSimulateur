## Decisions made

- Added field `noIndexFrom` (2022-01-01) because the 2023-02..2025-02 grids word the no-index surcharge 'à partir du 1er janvier 2022'.
- Items a grid does not print are null/omitted, never 0 (2022 grids print no Linky surcharge; 2026-08 VAT clause omits the CTA).
- Details stay open across re-renders (kVA/offers/period changes).
- PDF folder located only at run time through env/shell expansion; no path or identifier written to the repo.

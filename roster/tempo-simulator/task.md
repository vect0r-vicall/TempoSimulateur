# Task — tempo-simulator

Bootstrap new project TempoSimulateur: fully client-side (in-browser) EDF Tempo/HC-HP/Base offer simulator. User uploads the EDF index CSV export (template: <DATA_DIR>/mes-index-elec-<PDL>.csv); historical EDF price grids (<DATA_DIR>/grilles/) are extracted and hardcoded. Compare cost across Tempo, HC/HP and Base over a selectable period (default last 12 months). Bar chart by year/month/day with each selected offer's price side by side; period recap summing selected offers; colours reflect Tempo day colour (red/white/blue) and HC/HP ratio. Simple, clean, a bit fancy French UI (code in English). Runs fully in browser, no data/cookie/history stored server-side, resistant to bug/flaw/attack (no way to interact with the hosting server). Tempo calendar from 2022 hardcoded (extract or download public calendar); older data disabled. Light testing only: non-critical software.
